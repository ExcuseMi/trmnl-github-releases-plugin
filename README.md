### Description
Display the latest GitHub releases from your monitored repositories with powerful filtering options.<br /><br /> <strong>Features:</strong><br /> ● Filter by time period (show releases from last N days)<br /> ● Include or exclude pre-releases<br /> ● Include or exclude draft releases<br /> ● Show only the latest release per repository<br /> ● Show time since previous release for a project<br /> ● Multi-language support<br /> ● Dynamic spacing (TRMNL X Ready)
